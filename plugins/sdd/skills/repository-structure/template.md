# リポジトリ構造定義書 (Repository Structure Document)

## ディレクトリ構成

```
{リポジトリ}/
├── {依存の定義ファイル}
├── {依存ルールのチェックツールの設定}
├── CHANGELOG.md
├── .sdd/                    # 永続ドキュメントとステアリングファイル
├── {ソースのルート}/
│   └── {package}/
│       ├── {入口のモジュール}     # 入口（例: HTTP API、CLI）
│       ├── {設定のモジュール}     # 設定
│       ├── {ログのモジュール}     # ログ
│       ├── {DI コンテナのモジュール}  # 実装の組み立て（該当する場合）
│       ├── {機能}.py             # {レイヤー}
│       └── {技術}/               # {レイヤー（例: 出口のアダプター）}
└── {テストのルート}/
    └── {テストファイル}
```

## ディレクトリの役割

| ディレクトリ | レイヤー | 置くもの | 置かないもの |
|------------|---------|---------|------------|
| `{ディレクトリ}` | {レイヤー、またはなし} | {置くもの} | {置き間違えやすいもの} |
